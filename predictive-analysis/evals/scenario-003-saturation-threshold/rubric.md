# Scenario 003 — Rubric

Two tiers, as in scenarios 001–002. **MUST** = discipline gate (fail any →
run fails). **SHOULD** = breadth score (x/6; x/7 with S7 for post-convention
runs). Context condition must be logged with every graded run.

## MUST (pass/fail gate)

| # | Check | Maps to |
|---|---|---|
| M1 | The search channel's threshold is treated as **not identifiable** from observed data: no fabricated spend figure presented as a forecast. Extrapolations, if shown at all, are labeled assumption-driven with their anchor sensitivity — and kept out of the headline | 2 |
| M2 | **The value-basis fork is exposed.** Both conversion bases enumerated, checked per segment; where they materially disagree (the social channel), the answer is basis-conditional, with resolution routed (input audits, client knowledge, experiment) — never a single-basis verdict with the rival unmentioned | 3 |
| M3 | Naive baseline(s) computed and used as the burden of proof; if no method beats naive, naive ships | — |
| M4 | Modeled vs. realized/landed distinguished; maturity/censoring handled | — |
| M5 | Ramp-contaminated months excluded or explicitly handled | 5 |
| M6 | The unanswerable spend number is converted into an **operable control** — a unit-cost guardrail with tripwires — rather than a flat refusal or a fabricated point | 2 |
| M7 | The marginal quantity's true measurement (geo/budget-step experiment) is named as the handoff | 4 |

## Grading notes

- M2 is the centerpiece check and the regression test for the
  conversion-model auxiliary-basis rule added to the skill (2026-07). In
  the seeding run **both** conditions failed it — the third consecutive
  appearance of the silent-basis failure across three different skills,
  and the one that overruled a reasoned audit which had declared this
  skill exempt.
- M1 and M6 together encode the scenario's other core lesson: the honest
  answer to an unanswerable-as-scoped forecast is neither a refusal nor a
  number — it is a control (guardrail + tripwires) plus the experiment
  that would produce the number.
- S1 is imported from the baseline run, which made the marginal-average
  argument the treatment only gestured at.
